_Built and maintained by [Code-Hex](https://github.com/Code-Hex)_

A plugin for GraphQL Codegen to generate form validation schema (such as
[yup](https://github.com/jquense/yup), [zod](https://github.com/colinhacks/zod)) based on your
GraphQL schema for use in a client application.

## Examples

Set up your project per the GraphQL Codegen Docs, and specify this plugin in your `codegen.yml`:

```ts title="codegen.ts"
import type { CodegenConfig } from '@graphql-codegen/cli'

const config: CodegenConfig = {
  generates: {
    'path/to/graphql.ts': {
      plugins: ['typescript', 'typescript-validation-schema'],
      config: {
        strictScalars: true,
        schema: 'yup'
      }
    }
  }
}
export default config
```
