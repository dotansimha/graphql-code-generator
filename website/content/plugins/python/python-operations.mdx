title: python-operations
description:
  Document-driven GraphQL Code Generator plugin that emits Python operation types (per-operation
  result + variables). This plugin is based on the `python` plugin, but it generates operations
  instead of schema types.
hasOperationsNote: true
sidebarTitle: operations
---

For each `.graphql` operation document, `python-operations` generates:

- a per-operation **result type** (nested `BaseModel` classes, `snake_case` fields, reserved-keyword
  handling e.g. `from` → `from_`)
- **variables** as a `TypedDict`

Type references are generated to line up exactly with [`python`](/plugins/python/python), so run the
two plugins together.
